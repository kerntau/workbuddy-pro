# 数据展示改进计划（保留当前 UI）

## 范围

- 以当前项目组件、配色、字体、圆角、导航和控件为准，不重做页面设计。
- 调整数字格式、显示内容、内容高度和账号表格的空间分配。
- 演示使用独立目录与模拟接口，不读取或写入真实账号、配置、积分或用量库。
- 演示已确认，展示改动同步至正式页面；演示工具条、模拟接口和测试账号不进入正式应用。

## 1. 大数字与精确值

| 数值 | 简写 |
| --- | --- |
| 999 | 999 |
| 1,234 | 1.23K |
| 1,234,567 | 1.23M |
| 1,234,567,890 | 1.23B |
| 1,234,567,890,123 | 1.23T |

- 最多两位小数，去掉尾零；四舍五入后达到 1000 自动升一级。
- 统计卡、表格、图表坐标统一单位；悬停或点击提供完整数字和单位。
- 明细提供输入 / 输出 Token，不能只有总数的简写。
- 积分不按整数舍入；小额扣费保留必要小数，非零不得显示为 0。
- 未取到显示“未获取”，上游未给显示“未提供”，确认没有才显示 0。

## 2. 仪表盘与用量

- 保留现有卡片数量、图表位置和表格样式。
- 仪表盘保留实时账号 / 余额、今日使用、14 天趋势、积分变化与账号快照。
- 用量页保留 4 张卡片：区间请求、区间 Token、区间已记录扣费、期间调用密钥。
- 用量页卡片、趋势、模型表、密钥表必须服从同一日期范围；写明日期与统计时区。
- Token 图和失败次数不能共用相同单位的纵轴；保持现有图表外观，使用独立坐标并标注单位。
- 明细在当前单元格下补充输入 / 输出与精确值，名称允许换行；不增加一排新卡片。
- 图表提示显示完整日期、完整数值、单位；未来时段不当作已统计的 0。
- 更新失败就地说明并可重试，保留数据时标明旧值，不展示假的空数据。
- 上游官方统计沿用原卡片：6 个指标均匀分列，标签在上、数值在下；下方完整显示上游已有的按模型明细，不做一行散数字的空卡片。

## 3. 服务信息与模型列表（截图问题）

- 取消左右卡片强制拉伸同高，服务信息高度随内容变化。
- 账号目录允许换行，提供完整值和复制，不靠截断隐藏关键路径。
- 模型列表默认显示前 24 个，显示“已显示 24 / 共 82 个”，可展开全部、收起。
- 展开后完整保留全部模型，不删模型、不用空内容凑齐卡片高度。
- 后续相邻区块不设统一最小高度；只有同类指标卡保持一致高度。

## 4. 账号页横向滚动（第二张截图）

- 账号页与其他页面统一使用当前内容容器宽度，不单独加宽。
- 桌面表格保留账号、状态、积分、有效期、操作；启用代理时保留线路。
- UID 合并到账号名下方，默认前 8 / 后 4 位，点击文字即可复制完整值；悬停说明用途，成功后短暂显示“已复制”。不在每行重复放置独立复制图标。
- 长邮箱允许换行，不以完整 UID 或长名字撑开整张表。
- 次要操作放入现有风格的“更多”弹层，原有操作不丢失。
- 积分余额与到期提示分两行；有效期保留进度条和上次续期时间。
- 768–1023px 使用项目现有纵向账号卡片；大屏保持表格。
- 窄屏卡片与桌面表格必须同步应用 UID 点击复制与“更多”操作；窄屏不展开完整 UID、不在每张卡片底部平铺操作图标。卡片内余额和有效期各有标签，去掉占位的余额图标。
- 在 1024、1280、1440、1920px 验证表格不需要横向滚动；手机验证页面本身不横溢。

## 5. 演示与验收

- 同一份模拟数据可切换“当前显示 / 建议显示”，验证差异来自展示方式。
- 场景包括：12 亿级 Token、千级 / 百万级 Token、小额积分、长名字 / 路径、82 个模型、部分接口失败。
- 可查看仪表盘、用量统计、上游设置、账号页。
- 保留原项目样式；演示工具条只是预览控制，不进入正式 UI。
- 正式实现前另补统计口径：请求数目前不含全部调用，失败 / 性能依赖日志保留期，历史扣费缺失不能追溯成完整账本。
- 演示不伪造尚不存在的完整成功率、缓存历史、按分组历史用量。

## 执行顺序

1. 统一 K / M / B / T 和积分精度，补完整数值。
2. 修复服务信息留白、路径截断、模型列表展开。
3. 修复账号页宽度、UID 占列、操作栏挤占和窄屏布局。
4. 统一用量页时间范围，补充现有数据的细分展示。
5. 补持久统计后，再引入完整请求总数、成功率与数据完整度。

前四项按确认后的演示落地。第五项需要新增持久统计，不在本次展示调整中伪造历史指标。
